
          TT DCU FUNCTIONAL DESCRIPTION

Incarnations:  National ???
          Styra ST-4130

Pin Description
The DCU (data control unit) is a combination of a bi-directional
4 to 1
mux and a double buffered latch. It is used to interface the 32
bit
system data bus to the 8 bit peripheral chip controlled by the TT
DMAC.

D0-D31    TTL bi-dir     system data bus

PD0-PD7   TTL bi-dir     peripheral data bus

XCEN CMOS input     enables the D0-D31 pins as outputs

XPEN CMOS input     enables the PD0-PD7 pins as outputs

XLDI CMOS input     latches the state of the D0-D31 and
               PD0-PD7 pins when low

XHOLD     CMOS input     closes the secondary latches in the
               double buffer when low

XLWRD     CMOS input     causes the lower 16 bits of the latches
               to be gated onto the upper 16 bits. Used
               when CPU reads latch contents as a word.

XTHRU     CMOS input     causes the latches to be bypassed. Used
               to pass data directly thru the chip.

DA0,DA1   CMOS inputs    control which byte of the long word is
               envolved in a latching operation. The
               8 bit data from the PDx lines can be latched
               in one of four latches. Used to assemble
               bytes from the peripheral into long words
               or to select bytes from a long word to go to
               the peripheral.

S16X8     CMOS input     selects which 8 of the Dx lines are used
               for pass thru operations. Should be tied
               high in the TT.
