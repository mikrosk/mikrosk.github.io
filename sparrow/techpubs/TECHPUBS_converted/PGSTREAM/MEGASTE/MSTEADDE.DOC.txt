2.0 SUMMARY OF CHANGES


Two major areas have been changed in the Atari MEGA STE. These changes affect the Graphics Coprocessor and Floppy Disk Controller.


2.1 NEW COMBO IC (BLITTER GRAPHICS COPROCESSOR AND MCU)


The Graphics Coprocessor (BLITTER) and Memory Control Unit (MCU) now reside within the Atari COMBO IC. All functionality of the BLITTER and MCU ICs remains the same and are transparent to the system and user.


2.2 NEW FLOPPY DISK CONTROLLER (AJAX)


The Floppy Disk Controller has been replaced by a new AJAX IC which now allows for 2 MB (1.44 MB formatted) media to be supported. The switch S701 segment 7 must be changed to the "ON" position when a 2MB floppy drive is in the MegaSTe system.

NOTE: The floppy I/O cable for the 2MB floppy disk must also be turned over or reversed when inserted into the floppy drive. This is due to the fact the I/O pins in the 2MB floppy cable are in reverse order from the 1MB floppy interface cable. Interfacing and operation of the Floppy Drive in the system will not change.
