Atari Technical Bulletin
Number: DIAG-0001
Date: January 7, 1992
Page 1 of 1


Product(s) Affected:	ST, STE, MEGASTE, TT30
Model:			ALL
Type of ATB:		Information Only
ECO #:			N/A

Reason for ATB:

To inform the field as to the current level of cartridge diagnostics released by Atari. (as of January ,1992)

Notes:

Each of the following diagnostic set consists of two EPROMS per diagnostic. They are to be installed into the diagnostic PCB (part # C070208). Be sure to install the EPROM labeled "HI" into the U2 socket and "LO" into the U1 socket. See the appropriate service manual for general instructions on operating the diagnostics.

IMPORTANT: If the diagnostic pcb is used with out it's case the pcb must be installed into the computer with it's component side down. The eproms will be destroyed if the chips are on the top side. It is recommended that the pcb be reinstalled into it's case before using to eliminate this possibility.
